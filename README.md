# Open Mine

Open Mine is a phone-first AI workspace where models, projects, connectors, knowledge, skills, tools, missions and reusable context behave like objects in a spatial environment.

The primary navigation mechanic is an orbital selector. Floating cards represent workspace objects; the left rail switches categories; the context panel exposes actions; and the bottom carousel provides fast jumping.

The Engineering Vault is the durable layer for verified knowledge that can be reused by future projects and AI context.
